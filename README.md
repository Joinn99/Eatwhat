# 吃什么 · The Little Wheel

零依赖、单文件的手机友好转盘。打开 `index.html` 即可使用，无需安装或构建。

- 点击中心，3 秒后按权重揭晓结果；旋转期间禁止重复抽奖。
- 自定义菜单支持增删改选项及权重，默认权重 60，0 表示暂停参与。
- 扇区等分方便阅读，实际概率为选项权重 / 总权重。支持最多 60 项，长名称自动缩略，菜单与结果保留完整名称。
- 修改名称或权重后仅该选项的累计次数清零；其他选项保留次数。
- localStorage 保存设置、次数与最近 100 条历史，刷新后保留。历史保留抽中时名称。
- 无账号、无服务端、无第三方请求。记录只在当前浏览器、当前站点保存，不跨设备同步；清除浏览器数据会删除记录。
- 支持键盘操作及系统减少动态效果设置（仍等待 3 秒揭晓）。

## 分享菜单

在「自定义」中保存菜单，再点击「分享菜单 → 复制链接」，将链接发给朋友。
朋友打开链接后可预览并选择「使用这份菜单」，也可以保留自己的菜单。

- 链接只携带选项名称和权重，不包含次数、历史或本地 ID。
- 导入不同菜单时替换本地选项并从 0 次开始，原有历史保留；导入相同菜单不会清零。
- 菜单是分享时的快照，不会实时同步。修改后需要重新生成并发送链接。
- 菜单数据放在 URL 的 fragment（`#menu=...`）中，无需服务器或数据库。拿到链接的人可读取菜单内容。
- 请从已发布的 GitHub Pages 地址生成链接；localhost 或本地文件链接无法供朋友直接访问。
- 支持中文和 emoji。选项很多或名称很长时链接也会较长，请完整复制。

## GitHub Pages

将项目推送到 GitHub 仓库，在 **Settings → Pages → Source** 选择 **GitHub Actions**。
仓库已包含部署工作流，推送到 `main` 或 `master` 自动发布，也可在 Actions 中手动运行。
站点地址通常为 `https://<用户名>.github.io/<仓库名>/`。

也可以选择 **Deploy from a branch**，使用 `main` 分支的 `/ (root)` 目录，无需工作流。
